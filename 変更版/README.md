# スケジューリング実験 UI

Python 3.13 と uv を使用します。

```powershell
cd 変更版
uv sync
uv run streamlit run app.py
```

左側の設定からダミーデータを生成し、停止・ブロック時間を必要に応じて設定してから通常探索を実行します。結果と履歴は「結果・履歴」タブで確認できます。時刻の単位は分です。

SQLiteファイル`schedule.sqlite3`は変更版ディレクトリに作られます。ダミーデータを「リセット」すると新しいデータセットを作成し、過去のデータセット・実行履歴は残ります。利用中のデータセットは画面で切り替えられます。

製品一覧には受注で使用した製品のみ表示します。未使用の製品候補は既存データ生成処理が返していないため、保存対象には含めません。

停止・ブロック時間の編集内容は「設定を保存」または「通常探索を実行」で保存されます。段取ブロックは全作業者、加工ブロックは全機械に適用されます。加工ブロック中は加工が中断され、機械の予約時間は終了まで継続します。

「停止時間補助設定」では、停止種別を「稼働停止」か「段取のみ停止」から一つ選び、日数を指定して昼休み・夜間休止を自動生成できます。「稼働停止」は選択した機械・作業者の停止時間へ、「段取のみ停止」は全作業者共通の段取ブロックへ追加します。稼働停止では対象範囲を個別指定と機械全体／作業者全体から選べます。追加した行は「停止・ブロック設定」ページで確認・修正してから保存します。`horizon = 0`を9:00とし、昼休みは180～240分、夜間休止は480～1440分です。

ホライズンは既存アルゴリズムと同じく工程の段取時間と加工時間の合計です。停止・ブロック設定が多いと割当可能時間が不足し、実行できない場合があります。

テストは`uv run python -m unittest discover -s tests`で実行できます。
